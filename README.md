# customer_behaviour_analysis
data analytics project showcasing customer behavior analysis using python ,sql and power BI
📊 Data Analytics Project
Overview
This project demonstrates an end-to-end data analytics workflow, starting from raw data loading and exploration to SQL analysis, dashboard creation, and business reporting.
The project uses Python, PostgreSQL, Power BI, and Gamma to transform raw data into meaningful insights and present them through interactive visualizations and a professional report.
Dataset
The project uses a structured dataset containing relevant business data for analysis.
The dataset was:
•	Loaded and explored using Python
•	Checked for missing values and inconsistencies
•	Cleaned and prepared for analysis
•	Loaded into PostgreSQL for SQL-based analysis
•	Used as the foundation for the Power BI dashboard

Project Steps
1. Data Loading
The dataset was imported into Python using Pandas and examined to understand its structure, columns, data types, and overall quality.
2. Exploratory Data Analysis (EDA)
EDA was performed to identify:
•	Data distributions
•	Trends and patterns
•	Missing values
•	Duplicate records
•	Outliers
•	Relationships between variables
Visualizations were created to support the analysis and identify important patterns.
3. Data Cleaning
The dataset was prepared for analysis by:
•	Handling missing values
•	Removing duplicate records
•	Correcting data types
•	Standardizing column values
•	Handling inconsistent or invalid data
•	Preparing the final dataset for SQL analysis
4. PostgreSQL & SQL Analysis
The cleaned dataset was loaded into PostgreSQL.
SQL queries were written to perform business-focused analysis, including:
•	Aggregations
•	Filtering and sorting
•	Grouping
•	Joins
•	KPI calculations
•	Trend analysis
•	Business performance analysis
5. Power BI Dashboard
The analyzed data was connected to Power BI to create an interactive dashboard.
The dashboard includes:
•	Key Performance Indicators (KPIs)
•	Charts and visualizations
•	Trend analysis
•	Category-level analysis
•	Interactive filters and slicers
•	Business insights
6. Report Creation
The findings from the analysis and dashboard were summarized into a structured business report highlighting the major insights and observations.
7. Presentation
A professional presentation was created using Gamma to communicate the project, methodology, findings, and key business insights in a concise and visually appealing format.

How to Run
1. Clone the Repository
git clone <your-repository-url>
cd Data-Analytics-Project
2. Install Python Libraries
pip install pandas numpy matplotlib seaborn jupyter
3. Run the Notebook
Open Jupyter Notebook:
jupyter notebook
Run the EDA and data-cleaning notebook to reproduce the Python analysis.
4. PostgreSQL
•	Install PostgreSQL
•	Create a database
•	Import the cleaned dataset
•	Run the SQL queries provided in the sql/ folder
5. Power BI
Open the .pbix file using Power BI Desktop and update the data source connection if required.
6. Report & Presentation
The final report and Gamma presentation are available in their respective folders.
